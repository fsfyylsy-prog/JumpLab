# JumpLab · 起跳能力无线监测系统

基于 Qt/C++ 的人体起跳能力监测系统。服务端模拟测力台采集端，按"一次起跳 = 一条记录"的粒度向客户端推送该次起跳的力学指标；客户端完成实时表格、多视图曲线、成绩统计与疲劳分析。

> 原名"工业设备多参数远程监测系统"，已整体重构为运动生物力学方向的起跳能力监测项目。

## 一、功能特性

**服务端（JumpLabServer）**
- 图形化配置采集参数：受试者体重、起跳间隔范围、监听端口
- 每个客户端连接分配独立任务对象，交由 `QThreadPool` 线程池并发执行
- 子线程内以事件循环 + 单次触发定时器生成数据，不阻塞主线程
- 实时显示客户端上下线日志与在线数量

**客户端（JumpLabClient）**
- 实时接收并解析起跳数据，表格滚动展示最近 100 条记录
- 单图多轴折线图：起跳速度 / 最大峰值力 / 最大峰值功率三条曲线共享 X 轴，各自绑定独立 Y 轴并自动缩放，滚动窗口显示最近 30 次起跳
- **成绩统计与 PB 面板**：起跳次数、最佳腾空高度、最高起跳速度、最大峰值力、最大峰值功率、平均峰值功率；破纪录时卡片高亮并记录日志
- **疲劳指数分析**：滑动窗口基线对比 + 最小二乘趋势回归，三级告警（良好 / 轻度疲劳 / 重度疲劳）

## 二、监测指标与数据模型

| 指标 | 单位 | 典型范围 | 计算方式 |
| --- | --- | --- | --- |
数据按**运动员 / 体育生水平**标定（普通成年男性原地纵跳约 30~45 cm，本项目取 50~60 cm 区间）。

| 指标 | 单位 | 典型范围 | 计算方式 |
| --- | --- | --- | --- |
| 起跳离地速度 | m/s | 2.8 ~ 3.7 | 正态分布 N(3.35, 0.15²) × 疲劳因子 |
| 腾空高度 | cm | 40 ~ 65（集中在 50 ~ 60） | h = v² / (2g) |
| 最大峰值力 | N / BW | 1500 ~ 3000 N（2 ~ 4 BW） | F = BW × m × g |
| 最大峰值功率 | W / W·kg⁻¹ | 3500 ~ 5500 W（50 ~ 65 W/kg） | P = F × v × k，k ∈ [0.55, 0.80] |

**疲劳衰减因子**：`decay = 1 − 0.18 × (1 − e^(−n/50))`（n 为起跳序号）
随跳跃次数指数收敛下降，第 30 跳约衰减 8%，第 60 跳约衰减 13%，上限 18%。衰减幅度刻意控制在较小范围，保证长时间采集既能观察到真实的功率衰减趋势，又不会让腾空高度掉到不合理的低位。

**为什么峰值功率不等于 F × v**：峰值力出现在蹬伸早期、离地速度峰值出现在蹬伸末期，二者不同时达到最大，故引入 0.55~0.80 的功率系数，结果落在真实测力台的实测区间内。

## 三、通信协议

单行 JSON（`QJsonDocument::Compact`）+ `\n` 换行作为帧界定符，接收端用 `canReadLine()` 判断整帧，避免 TCP 粘包/拆包。

```json
{"type":"jump","seq":12,"weight":"70.0","speed":"3.34","height":"56.9",
 "peakForce":"1963.4","peakForceBW":"2.87","peakPower":"4426.9",
 "peakPowerPerKg":"63.2","times":"2026-10-22 15:20:31"}
```

## 四、疲劳指数算法

1. **基线**：遍历历史所有长度为 5 的滑动窗口，取平均峰值功率的最高值，代表未疲劳时的输出水平
2. **当前值**：最近 5 次起跳的平均峰值功率
3. **疲劳指数** `FI = (基线 − 当前值) / 基线 × 100%`
4. **趋势**：对最近 10 次起跳的峰值功率做最小二乘线性回归，得到斜率（W/次），判定功率持续下降、回升或平稳
5. **分级**：`FI < 12%` 状态良好（绿）；`12% ≤ FI < 25%` 轻度疲劳（黄）；`FI ≥ 25%` 重度疲劳（红，建议停止训练）

## 五、运行方式

环境：Qt 5.14.2 + MinGW 32bit

```bash
# 服务端
cd "1015 monitorServer/monitorServer"
qmake && mingw32-make

# 客户端
cd "1015 monitorClient/monitorClient"
qmake && mingw32-make
```

运行顺序：
1. 启动 `JumpLabServer` → 设置体重与起跳间隔 → 点击"启动服务器"
2. 启动 `JumpLabClient` → 输入服务器 IP（本机 `127.0.0.1`）与端口（默认 `8080`）→ 点击"连接服务器"
3. 每约 3 秒收到一次起跳数据，表格、曲线、统计卡片与疲劳指数实时刷新

## 六、技术栈

- **语言/框架**：C++11、Qt 5.14（QtCore / QtGui / QtWidgets / QtNetwork / QtCharts）
- **网络**：`QTcpServer` / `QTcpSocket`，长连接、按行帧界定
- **并发**：`QThreadPool` + `QRunnable` + 子线程 `QEventLoop`，跨线程信号槽通信
- **数据交换**：`QJsonObject` / `QJsonDocument`
- **可视化**：`QChart` / `QLineSeries` / `QValueAxis` / `QChartView`
- **界面**：深色科技风，控件的背景色/前景色/边框/字体等样式全部定义在各控件的 `styleSheet` 与 `font` 属性中，可直接在 Qt Designer 属性面板修改，代码中不写静态样式
